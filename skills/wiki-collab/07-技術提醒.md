# 技術提醒

> 動 Office 檔前、寫 git 指令前讀。每條後面的實例是「為什麼有這條」，不要刪。
> 上層：`SKILL.md`

## Office 檔

- 🔴 **互動開啟＝改檔**：桌面 App 開 `.docx`／`.xlsx`／`.pptx` 再存，格式正規化 → size／md5 變、副本立刻「過期」、且被自動備份收進版本庫。
  程式化 COM 明確 `.Save()` 實測 byte 零變動。→ 順序**先 commit → 再開檔 → 再比對**。判準是內容完好，不是 byte 相同。
- 🔴 **`.xlsx`／`.docx` 的「md5 不同」資訊量接近零**：它們是 zip，每次存檔重寫 metadata／calcChain。只看 md5 會卡住，只看 mtime 會誤判。
  **覆蓋前先跑「逐格＋列／欄／合併」比對。** `.xls` 檔尾 metadata 也會自行漂移，同理。
- 🔴 **改完表格 MUST 比對「列數」＋「全表逐格 diff」，不可只驗改過的格**
  > 實例：逐格寫入使含垂直合併的表結構塌陷、一整列消失；修復時又覆蓋掉另一列 13 欄。連過多個 commit，雙方驗收都沒發現。
  → ① 比改前改後列數 ② 抓全部列識別碼查連續性與重複 ③ 關鍵表逐格 diff vs git 基準版。
- 🔴 **xlsx／docx 沒有衝突提示**：後存檔的無聲覆蓋先存檔的，雙方都不會發現。→ 動之前 `ListAgents` ＋登記佔用。
- ⚠️ 帶列印設定的 `.xlsx` 用 Excel COM，不用 `openpyxl`（會丟 `printerSettings`）。
- ⚠️ 0-indexed（`xlrd`）與 1-indexed（COM）混用，同一格會差一列 —— 派工單寫座標時註明基準。
- 🔴 **絕不 `Stop-Process` Word／Excel**（見 SKILL 絕對禁止）。`Save()` 說唯讀但磁碟 `IsReadOnly=False` ＝ 該檔被另一個實例開著，
  通常是我方留下的無視窗殘留 → 回報主管，由使用者關。

## git

- 🔴 **`git add <路徑> && git commit` 不等於只提交那個檔** —— commit 提交整個 index，含 peer 已 staged 的。→ **`git commit --only <路徑>`**。
  新檔先 `git add` 再 `--only` 同路徑（未追蹤檔純 pathspec 會失敗）。`--only` 後路徑**不要加 `--`**（會把 `-m` 當路徑）。
- 🔴 **凍結期間禁用 `git add -A`／`git add -- <目錄>`** —— 會掃進凍結檔與他人未提交編輯，歸屬證據只有 commit message，日後查不出誰動的。
- 🔴 **自動備份（obsidian-git autoCommit）吃掉歸屬，任何 git 紀律都擋不住**：它會突破凍結、把 `cp` 那一步收走、讓 `git checkout --` 還原到污染版。
  → 唯一補救是在 `wiki/log.md` 記明真實歸屬；還原用 `git checkout <乾淨commit> -- <路徑>`。
- ⚠️ rebase 撞檔用 `--autostash`，**不要手動 `git stash`** —— 會把 peer 的未提交工作暫存起來，你若中斷，它不知情。
- ⚠️ `cp -p` 保留 mtime，git 的 stat cache 「mtime＋size 相同就不重新雜湊」→ **內容已變、`git status` 仍乾淨**。
  → 收尾用 `git update-index --really-refresh` 再 `git diff --name-only HEAD`。
- ⚠️ repo 開 CRLF 轉換時，新增 `.md` 寫檔當下算的 hash 與 checkout 後不同 —— manifest hash 要在 checkout 過一輪後再算。二進位檔不受影響。
- ⚠️ `.gitattributes` 沒標 `*.xls* *.doc* *.ppt* *.pdf binary` 時，磁碟 md5 可能 ≠ blob md5 —— 派工單寫 md5 要註明取自哪邊。

## Python

- ⚠️ `__pycache__/*.pyc` 會讓改過的 `_lib` 看起來沒生效（多 session 各自 import 時尤其）。懷疑時刪 `__pycache__` 再跑。
- 腳本讀 Office 檔加唯讀旗標（Word COM：`Documents.Open(path, False, True)` 第三參數 ReadOnly）。

## 字串替換

- 🔴 批次改檔名／替換字串要**錨定副檔名或完整檔名**，不可只靠「編號＋版次」—— 同一編號會出現在不同類型檔名而語意不同。
  改完跑「全列路徑存在性驗證」（manifest 斷鏈就是這樣來的）。
- 🔴 PDF 文字抽取對堆疊符號（非對稱公差之類）不可信，且錯誤常自洽不自曝 —— 涉及數值回頭看原圖。**每種抽取法都有它看不見的東西，結論標明方法。**
