# 🔴 四條格式規則（比段落順序更重要）

| # | 規則 | 解決什麼 |
|---|---|---|
| 1 | **表格不對齊，`\|` 之間不補空白** | 對齊空白實測佔單檔 50–60% 字元，**markdown 渲染結果完全相同** |
| 2 | **時序／沿革一律連出去** | 歷史只增不減，不該待在輪替快照裡 |
| 3 | **③ 只寫未解決的**，解決即刪 | 缺口表會持續累積，且已結案項目會被重新報給使用者 |
| 4 | **靜態段（①②⑤）寫完不再動**；日常維護只碰 ③④ | 三種生命週期混在一起 → 每次都得重讀整份 |
