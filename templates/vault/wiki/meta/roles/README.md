# 角色卡

一個角色一張卡（`<角色>.md`），讓 session 關掉、`/clear` 或換視窗之後接得上同一份工作 ——
卡上記職責、必讀清單（最多 5 份）、守門腳本、辦公室登記參數、進行中事項，
以及目前持有者的 ListAgents 名稱。

**為什麼需要**：session 沒有跨視窗記憶，ListAgents 名稱在重開或 `/clear` 後也會變
（只有使用者能 `/rename`）。把「這個角色是誰、要讀什麼、做到哪」固定在 vault 裡，新 session 才照卡接得住。

| 要做什麼 | 怎麼做 |
|---|---|
| 接手角色 | `/wiki-role take <角色>`（或對它說「你是 <角色>，接手」） |
| 看誰持有哪張卡 | `/wiki-role list` |
| 建新卡 | `/wiki-role new <角色>` —— 使用者明說要建才做 |
| 收工更新進行中事項 | `wiki-end` 會呼叫，不用自己記得 |

範本在 `Templates/角色卡模板.md`，流程在 plugin `wiki-collabteam` 的 `role.md`。

🔴 「定義」段（職責、必讀、守門腳本）**只有使用者或主管能改**，持有者只維護「進行中事項」。

本資料夾空的沒關係 —— 有專責角色要交接時才建卡。
